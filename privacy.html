차트퀴즈 개인정보처리방침

서비스: 인스타그램 @daily_chartquiz 댓글 자동 답장 · 유튜브 쇼츠 자동 업로드 · 시행일 2026년 10월 21일 (유튜브 항목 추가 2026년 10월 26일)

1. 어떤 서비스인가요

@daily_chartquiz 게시물에 댓글을 남기면, 해당 영상의 차트 패턴 학습 자료 링크를 인스타그램 DM으로 보내 드리는 자동 답장 기능입니다. 같은 게시물에서는 한 사람에게 1회만 보냅니다. 교육용 자료이며 투자 권유가 아닙니다.

2. 처리하는 정보

  • 댓글 ID, 댓글 내용, 댓글 작성 시각
  • 댓글 작성자의 인스타그램 사용자 이름

이 정보는 Instagram API를 통해 @daily_chartquiz 계정에 달린 댓글에 한해서만 받아옵니다. 이름, 연락처, 위치 등 다른 정보는 받지 않습니다.

3. 이용 목적

  • 자료를 보낼 댓글인지 확인
  • 댓글 작성자에게 학습 자료 DM 1회 발송 및 댓글에 안내 답글 작성
  • 같은 사람에게 중복 발송하지 않기 위한 확인

광고, 판매, 제3자 제공에는 사용하지 않습니다.

4. 보관 기간

중복 발송 방지를 위해 댓글 ID와, 게시물·사용자 조합을 되돌릴 수 없게 변환한 값(해시)만 운영자 컴퓨터에 저장하며, 일정 건수를 넘으면 오래된 것부터 자동 삭제됩니다. 댓글 내용과 사용자 이름은 저장하지 않습니다.

5. 제3자 제공

수집한 정보를 다른 사람이나 회사에 제공하지 않습니다. 메시지는 Meta(Instagram) 플랫폼을 통해 전달되며, Instagram 자체의 정보 처리는 Meta 개인정보처리방침을 따릅니다.

6. 데이터 삭제 요청

저장된 정보 삭제를 원하시면 인스타그램 @daily_chartquiz로 "데이터 삭제 요청"이라고 DM을 보내 주세요. 확인 후 7일 이내에 삭제하고 답장 드립니다. 댓글을 직접 삭제하셔도 이후 처리 대상에서 제외됩니다.

7. 문의

인스타그램 @daily_chartquiz DM으로 문의해 주세요.

8. 유튜브 자동 업로드 (Google API)

차트퀴즈 운영자는 직접 만든 차트 퀴즈 영상을 운영자 본인의 유튜브 채널에 올리기 위해 Google의 YouTube Data API를 사용합니다.

  • 요청 권한: youtube.upload (동영상 업로드) 하나뿐입니다. 시청자나 다른 사람의 Google 계정 정보에는 접근하지 않습니다.
  • 로그인 정보(토큰)는 운영자 컴퓨터에만 저장되며, 업로드 외의 목적으로 쓰거나 다른 사람·회사에 제공하지 않습니다.
  • Google API로 받은 정보를 광고, 판매, AI 학습 등에 사용하지 않으며, Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
  • 연결 해제: Google 계정의 서드 파티 액세스 관리에서 언제든지 권한을 취소할 수 있습니다.

English summary

This app replies to comments on @daily_chartquiz posts by sending one Instagram direct message per person per post with a link to educational chart-pattern material. It reads only the comment ID, text, timestamp and commenter username of comments on our own posts, stores only comment IDs and an irreversible hash of the post/user pair to prevent duplicate messages (oldest removed automatically), and never sells or shares data with third parties. To request deletion, send a DM saying "data deletion request" to @daily_chartquiz; we delete within 7 days. Separately, the operator uses the YouTube Data API (scope youtube.upload only) to upload the operator's own quiz videos to the operator's own YouTube channel; the OAuth token stays on the operator's computer, is never shared, and Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
